CONSTRAINT
=================================================================
BNEFORE INSERTING DATA INTO TABLE YOU HAVE TO SATISFY CERTAIN RULES AND REGULATIONS
CALLED CONSTRAINT
TYPES OF CONSTRAINT
================================================
1.PRIMARY KEY===IT DOES NOT ACCEPT NULL VALUE AS WELL AS DUPLICATE VALUE
2.UNIQUE KEY===IT DOES NOT ACCEPT DUPLICATE VALUE BUT ACCEPT NULL VALUE
3.NOT NULL==YOU CAN'T LEFT BLANK TO THE FIELD
4.CHECK CONSTRAINT===YOU HAVE TO SATISFY PREDEFINED VALUES
                    GENDER===M/F
                    AGE==21 TO 58
5.FOREIGN KEY===IT WILL ACCEPT OTHER TABLE PRIMARY KEY VALUE ONLY

CREATE TABLE EMP
(EID VARCHAR(10),
 ENAME VARCHAR(25) NOT NULL,
 JOB   VARCHAR(25),
 SAL   DECIMAL,
 COMM  DECIMAL,
 HIREDATE DATE,
 DEPTNO VARCHAR(10),
 CONSTRAINT EMP_EID_PK PRIMARY KEY(EID),
 CONSTRAINT EMP_DEPTNO_FK FOREIGN KEY(DEPTNO) REFERENCES DEPT(DEPTNO)
);
